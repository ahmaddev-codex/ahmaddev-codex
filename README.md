## 🏛️ Executive Summary

I am a **Senior Full-Stack & Distributed Systems Engineer**, tech community executive, and the architect behind **[GetCracked](https://getcracked-dev.vercel.app)** and **[Tutelee](https://www.tutelee.com)**. Recognized as one of **Nigeria's Top 20 Student Tech Leaders**, I serve as **President of the LASU Tech Society** (coordinating all faculty tech ecosystems) and **Coordinator of the AI, Robotics and Automation Lab** at LASU Unipod (Innovation Hub).

## 🛠️ Flagship Systems & Architectures

### ⚡ [GetCracked](https://getcracked-dev.vercel.app) — In-Browser Spatial DSA & Distributed System Design Engine
<p>
  <a href="https://getcracked-dev.vercel.app">
    <img src="https://img.shields.io/badge/Live%20Platform-getcracked--dev.vercel.app-000000?style=for-the-badge&logo=vercel&logoColor=white" alt="GetCracked Live" />
  </a>
  &nbsp;
  <img src="https://img.shields.io/badge/Runtime-Zero--Latency%20WASM-4285F4?style=for-the-badge&logo=webassembly&logoColor=white" alt="WASM" />
  &nbsp;
  <img src="https://img.shields.io/badge/Architecture-Distributed%20Canvas-34A853?style=for-the-badge" alt="Distributed Architecture" />
</p>

> **"Build real systems. Step by step. In your browser."** — An interactive engineering platform bridging the gap between algorithmic theory and production systems design without slides or pre-recorded videos.

- **Zero-Latency Client-Side WASM Execution**:
  - Embedded real language interpreters compiled to **WebAssembly (WASM)** executing entirely within dedicated browser Web Workers.
  - Multi-language sandbox supporting **5 programming languages** (TypeScript, JavaScript, Python, Java, C++, and Go) with zero server execution latency, zero container startup queues, and zero compute infrastructure costs.
- **Physics-Based Spatial Motion Visualizer**:
  - Engineered a coordinate-explicit spatial rendering engine where elements physically lift, follow geometric Bezier translation arcs, and land into memory slots—replacing static pre-rendered animations.
  - Line-by-line synchronized execution stepping with live code pointers across **8 core data structures**: Arrays, Linked Lists, Stacks, Queues, Binary Trees, BSTs, Heaps, and Hash Maps.
- **Interactive Distributed System Design Canvas & Scored Labs**:
  - Real-time distributed architecture whiteboard simulating live packet traffic flows: `Cloudflare Edge CDN (85k req/s, 8ms) ➔ Envoy API Gateway (48k req/s, 14ms) ➔ Go Core Microservices across 3 AZs (P99 32ms) ➔ Redis Primary Cluster (1.2ms) & Distributed PostgreSQL`.
  - Built-in capacity estimation calculators for storage footprint, QPS, P99 latency, and network bandwidth.
  - 6 Scored Design Labs evaluating interview reasoning (requirements, capacity math, API design, schema modeling, horizontal scaling, and bottleneck mitigation) across a 10-dimensional architectural matrix.
- **Comprehensive Curriculum & AI Mock Interviews**:
  - 31 lessons (20 DSA + 11 System Design), 42 practice problems with progressive hints and hidden test suites, and 8 multi-step production builds (32 build steps: LRU cache, distributed token-bucket rate limiter, undo/redo state tree).
  - 8 verified first-party FAANG interview guides (Amazon, Google, Meta, Microsoft, Apple, Netflix, Uber) and timed 45-minute mock interview rounds with a Socratic AI interviewer that listens, challenges assumptions, and scores architectural trade-offs.
- **Tech Stack**: `Next.js 15` `TypeScript` `WebAssembly (WASM)` `Web Workers` `HTML5 Canvas / SVG Vector Engine` `TailwindCSS` `Vercel`

  </a>
  &nbsp;
  <img src="https://img.shields.io/badge/Video-Daily.co%20WebRTC-0A66C2?style=for-the-badge&logo=webrtc&logoColor=white" alt="Daily.co WebRTC" />
  &nbsp;
  <img src="https://img.shields.io/badge/Reach-15%2B%20Countries%20•%2050%2B%20Languages-EA4335?style=for-the-badge" alt="Global Reach" />
</p>

> **"Where culture meets world-class learning."** — An international educational marketplace built to solve cultural disconnect in global education, connecting diaspora families across 15+ countries with certified cultural mentors.

- **Native Daily.co WebRTC Video Suite**:
  - Fully integrated in-browser video classrooms eliminating fragmented third-party meeting links (Zoom/Google Meet).
  - Delivers sub-second latency 1-on-1 and group classrooms with interactive whiteboards, screen sharing, host session controls, and automated session recording.
- **The Safeguard Stack & Automated Escrow Rails**:
  - *Tutor Identity & Background Screening*: Enforces mandatory multi-layer identity verification and background screening for every educator prior to their first session.
  - *Credential-Backed Qualifications*: Independently verifies academic degrees, certifications, and teaching track records.
  - *Automated Escrow State Machine*: Funds are locked in an escrow state machine upon booking and released only upon verified session delivery—powering automated weekly tutor disbursements and completely eliminating unpaid invoice chasing.
- **Global Cross-Timezone Scheduling Matrix**:
  - Proprietary timezone negotiation matrix resolving scheduling conflicts across **15+ countries** (UK, US, Canada, Australia, Nigeria, Ghana, Kenya, South Africa, Germany, France, UAE, Saudi Arabia, etc.) supporting **50+ languages**.
- **Distributed Edge & Search Infrastructure**:
  - Session recordings, lecture notes, and classroom assets streamed to Cloudflare R2 object storage.
  - Fastify microservices hosted on Railway with PostgreSQL persistence and Meilisearch delivering sub-millisecond query results across tutor subjects, language dialects, and availability.
- **Tech Stack**: `Next.js 14` `Fastify / Node.js` `Daily.co WebRTC` `PostgreSQL` `Cloudflare R2` `Meilisearch` `Railway` `Docker`
